# Underdog ShaderLab V01: source-owned shader compiler diagnostics

Status: experimental implementation on Host 02, no universal game integration or driver patch.
Scope: local project candidate D3D_COMPAT_UNDERDOG_01. Google Drive scope not yet promoted.

## Reuse-first toolchain
Host 02 already has Microsoft Windows SDK 10.0.26100.0 x64 FXC and DXC, MSVC 2022 Build Tools, Python 3.14.2 and previously registered PresentMon 2.6.0. Compiler hashes and paths live in 00_MANIFESTS/SHADERLAB_TOOLCHAIN_V01.json; SDK executables are referenced, not copied into Git. DXVK v3.0, Intel Graphics Compiler, SPIRV-Tools, 3Dmigoto and ReShade remain research-only references. No code from those repositories is vendored.

## Architecture and controls
tools/shaderlab.py extracts Arena's source-owned HLSL from examples/games/underdog_arena_v03.cpp, reproduces its exact structured-buffer and typed-texture variants, computes SHA-256 manifests, compiles FXC cs_5_1 O1/O3 and optionally offline-only DXC cs_6_0, and records diagnostics and bytecode hashes. Shader binaries are created only in a temporary directory and removed after compilation.

Arena's original shader optimization O1 remains default. Set UNDERDOG_SHADERLAB_VARIANT=O3 for an opt-in O3 D3DCompile run; an unrecognized nonempty value fails fast. This changes compiler flags, not resources, dispatch dimensions, game installation, or GPU drivers. Existing texture output backend selectors remain independent.

## Reproduce
From the repository root on Host 02:

    python -m unittest discover -s tests -p test_shaderlab.py -v
    python tools/shaderlab.py inventory
    python tools/shaderlab.py compile
    python tools/shaderlab.py games --games-root "C:\AIOS\04_WORKSPACES\PC_GAME_RE_LAB_01\GAMES"

Compiler diagnostics and host game inventory are written to 07_EXECUTION/SHADERLAB_V01 in the local workspace when --output is supplied. Do not check in generated bytecode or source-binary archives as GitHub code assets.

## Evidence interpretation
* Successful offline compilation is NOT proof of hardware execution, rendering quality, performance gain or compatibility with a game.
* DXC shader model 6 success is specifically offline-only until real feature probes and hardware execution support it.
* GPU acceptance requires output image identity/tolerance, a healthy device, repeated runs and measured performance.
* A folder under the game lab is only a candidate; no third-party game compatibility is promoted based on inventory.
* FXC warned X4000 about a potentially uninitialized value in the original ray-intersection shader. Preserve as an investigation finding. Do not simultaneously alter shader logic while comparing optimization flags.

## V01 results: Host 02 acceptance
* FXC O1/O3 for structured/typed shaders and DXC offline SM6: 6/6 compilation passes.
* Hardware-free regression: 4/4 Python tests; CTest 2/2 tests on Windows Build Tools.

* Native game integration: NONE yet; do not conflate executable import inspection with successful ShaderLab integration.
